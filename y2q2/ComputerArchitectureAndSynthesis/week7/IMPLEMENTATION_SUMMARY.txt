================================================================================
DATAPATH FLOW FOR LW/SW
================================================================================

LOAD WORD (LW):
1. Decode: Control Unit sets RegWrite=1, ALUSrc=1, MemWrite=0, ResultSrc=1
2. Execute: ALU calculates address = Register[rs1] + Immediate
3. Memory: Data_Memory reads from calculated address
4. Writeback: Result mux selects memory data, writes to Register[rd]

STORE WORD (SW):
1. Decode: Control Unit sets RegWrite=0, ALUSrc=1, MemWrite=1, ResultSrc=X
2. Execute: ALU calculates address = Register[rs1] + Immediate
3. Memory: Data_Memory writes Register[rs2] to calculated address
4. Writeback: None (RegWrite=0)
