# gsync — design spec

Date: 2026-09-15
Status: approved, implemented (v0.1.0)

## Problem

Work gets finished but never committed/pushed. Syncthing was used to move repos
between devices, but syncing `.git/` internals produces conflicts. Git itself
should be the sync layer, and committing/pushing should happen automatically with
professional Conventional Commit messages written by an AI (Cline CLI, DeepSeek).

## Goals

- Automatically commit, rebase and push a configured list of repos.
- Commit only when the working tree has been idle, plus on suspend, shutdown and
  manual invocation.
- Commit messages follow Conventional Commits, generated by Cline; always fall back
  to a deterministic message if the AI is unavailable or returns garbage.
- Run on Arch Linux (systemd) and macOS (launchd).

## Non-goals

- Resolving merge conflicts automatically.
- Managing submodules (their contents and pointers are never staged by gsync).
- Force pushing, history rewriting, branch management.

## Layout

```
projects/gsync/
  gsync              main script (bash 3.2 compatible)
  prompt.md          system prompt for the AI
  config.example     sample config
  install.sh         installs for Linux or macOS (--uninstall, --no-sudo)
  linux/             systemd units
  macos/             launchd plist template
  tests/run.sh       test suite (scratch repos + local bare remotes + fake AI)
  README.md
  docs/spec.md
```

Dependencies: git, bash, jq (for parsing Cline JSON), cline (optional).

## Configuration

`${GSYNC_CONFIG:-~/.config/gsync/config}`, a sourced shell file:

| Key | Default | Meaning |
|---|---|---|
| `REPOS` | `"$HOME/study $HOME/study/work"` | space-separated repo paths |
| `IDLE_MINUTES` | `10` | minutes without file changes before auto-commit |
| `AI_CMD` | `cline` | AI CLI (may include extra args); empty disables AI |
| `AI_TIMEOUT` | `60` | seconds before AI is abandoned |
| `MAX_DIFF_LINES` | `300` | diff lines sent to AI per group |
| `MAX_DIFF_BYTES` | `60000` | diff bytes sent to AI per group (argv limit) |

`install.sh` appends the installing shell's `PATH` (and `SSH_AUTH_SOCK` when it
lives under `$XDG_RUNTIME_DIR`) so services find git, jq and cline.

## CLI

```
gsync            sync all repos now (ignores idle check)
gsync --idle     only commit repos that have been idle (used by timer)
gsync --fast     AI_TIMEOUT capped at 20s (used by sleep/shutdown)
gsync -n         dry run: print planned commits, change nothing, no AI call
gsync -h | -V
```

Exit status is non-zero if any repo needed attention (conflict, detached HEAD,
failed commit). Being offline is not an error.

## Per-repo algorithm

Each repo runs in its own subshell.

1. Skip (log) if the path is not a git work tree; `cd` to its top level.
2. Acquire `$GIT_DIR/gsync.lock` via `mkdir`; skip if held. Locks older than
   30 minutes are removed. Released on exit via trap.
3. Refuse (notify) during a rebase/merge/cherry-pick/revert, with unmerged files,
   or on a detached HEAD.
4. **Commit.** Collect changes from
   `git status --porcelain=v1 -z --no-renames --untracked-files=all --ignore-submodules=all`,
   skipping `.gitmodules` paths and untracked nested repositories (entries ending
   in `/`).
   - With `--idle`: if any existing changed path has an mtime within
     `IDLE_MINUTES`, do not commit.
   - Group paths by scope = first two directories of the path's directory
     (`projects/esp32/src/main.c` → `projects/esp32`, `projects/calc.py` →
     `projects`, `README.md` → `root`). For each group in sorted order:
     `git add -A` (except staged deletions), build the AI input, get a message,
     `git commit -F <msg> -- <paths>` so only that group is committed.
5. **Rebase and push.** Skip if there is no remote. `git fetch` (failure = offline,
   log and stop). Without an upstream: track `origin/<branch>` if it exists,
   otherwise `git push -u origin <branch>`. If behind: `git rebase @{u}` only when
   tracked files are clean; on failure `git rebase --abort` and notify. If ahead
   and not behind: push; failure is logged and retried next run.

Committing before rebasing avoids autostash conflicts; local commits are never
lost if the rebase fails.

## AI message generation

Input: repository name, suggested scope (last component of the group scope,
lowercased), `git diff --cached --stat`, and the staged diff truncated to
`MAX_DIFF_LINES` / `MAX_DIFF_BYTES`.

Command, with stdin from `/dev/null`, in an empty temp working directory, under a
portable timeout:

```
$AI_CMD -c <tmpdir> -s "<prompt.md>" --auto-approve false --json "<input>"
```

The message is `.text` of the `run_result` JSON line. Code-fence lines and
leading blank lines are stripped.

Validation:

- First line matches
  `^(feat|fix|docs|refactor|chore|test|style|perf|build|ci)(\([a-z0-9._/-]+\))?!?: [^ ].*$`
  and is at most 72 characters.
- If there is a second line, it is blank.

Fallback: `chore(<scope>): sync YYYY-MM-DD HH:MM from <host>` (no scope for
`root`). Every commit ends with a `Device: <host>` trailer.

## Triggers

| | Arch | macOS |
|---|---|---|
| Every 15 min | `gsync.timer` (user) → `gsync --idle` | LaunchAgent `StartInterval 900` → `gsync --idle` |
| Suspend | system `gsync-sleep.service`, `Before=sleep.target`, `User=<you>` → `gsync --fast` | `sleepwatcher` `~/.sleep` → `gsync --fast` |
| Shutdown/logout | user `gsync-shutdown.service`, `ExecStop=gsync --fast` | not supported (no reliable hook) |
| Manual | `gsync` symlinked into `~/.local/bin` | same |

## Notifications and logging

Everything is logged to `~/.local/state/gsync/gsync.log` (and to stderr when run
in a terminal). Notifications only for problems needing the user: Linux
`notify-send`, macOS `osascript`. `GSYNC_NO_NOTIFY=1` disables them.

## Testing

`tests/run.sh` covers: AI message used and pushed, grouping, idle skip, invalid /
too long / fenced / failing / disabled / slow AI, AI input contents, rebasing
remote changes, pulling with nothing to commit, rebase conflict abort, offline
retry, dry run, deletions and renames, pre-staged files, submodules and nested
repos untouched, new branch push, detached HEAD, lock handling, missing repo,
paths with spaces and glob characters.
