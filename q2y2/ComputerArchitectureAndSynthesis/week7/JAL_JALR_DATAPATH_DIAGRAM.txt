## Key Signal Changes

### 1. Control Unit Outputs (NEW/MODIFIED)
- **Jump** (NEW): High for JAL/JALR instructions
- **ResultSrc[1:0]** (MODIFIED): 
  - Was 1-bit, now 2-bits
  - "10" enables PC+4 writeback for return address

### 2. PC Selection Logic (MODIFIED)
```vhdl
-- Old (Week 5):
PC_next <= BranchTarget when PCSrc='1' else PC_plus4

-- New (with JAL/JALR):
PC_next <= JumpTarget when (Jump='1' and opcode="1100111") else  -- JALR
           BranchTarget when (Jump='1' or PCSrc='1') else         -- JAL/BEQ
           PC_plus4                                                -- Normal
```

### 3. Result Multiplexer (MODIFIED)
```vhdl
-- Old (Week 5):
Result <= ReadData when ResultSrc='1' else ALUResult

-- New (with JAL/JALR):
Result <= ReadData when ResultSrc="01" else    -- Load
          PC_plus4 when ResultSrc="10" else     -- JAL/JALR return address
          ALUResult                             -- Default
```

## Instruction Flow Examples

### JAL Execution:
```
Cycle 1: PC=0x08, Instruction: jal x1, +20
  ├─ Control: Jump='1', ResultSrc="10"
  ├─ ImmExt outputs: 0x00000014 (20)
  ├─ BranchTarget = 0x08 + 0x14 = 0x1C
  ├─ Result = PC_plus4 = 0x0C
  └─ PC_next = BranchTarget = 0x1C

Cycle 2: PC=0x1C (function entry)
  └─ x1 = 0x0C (return address saved)
```

### JALR Execution:
```
Cycle 1: PC=0x20, Instruction: jalr x0, x1, 0
  ├─ Control: Jump='1', ResultSrc="10", ALUSrc='1'
  ├─ ALU: x1 + 0 = 0x0C
  ├─ JumpTarget = 0x0C & 0xFFFFFFFE = 0x0C
  ├─ Result = PC_plus4 = 0x24 (but x0 ignores writes)
  └─ PC_next = JumpTarget = 0x0C

Cycle 2: PC=0x0C (returned to caller)
```

## Summary

The JAL/JALR implementation adds minimal hardware:
- 1 new control signal (Jump)
- 1 wider control signal (ResultSrc: 1→2 bits)
- 1 new multiplexer input (PC+4 to Result)
- Enhanced PC selection logic

This enables full function call/return capability! 🎉
