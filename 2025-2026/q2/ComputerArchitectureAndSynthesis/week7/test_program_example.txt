SAMPLE TEST PROGRAM FOR LOAD/STORE OPERATIONS
============================================================

This file shows example RISC-V assembly instructions and their
machine code encodings to test your data memory implementation.

You can add these to your Instruction_Memory.vhd to test LW/SW.

------------------------------------------------------------
Test Program 1: Basic Store and Load
------------------------------------------------------------

Assembly:
    addi x1, x0, 5      # x1 = 5
    addi x2, x0, 12     # x2 = 12
    sw x1, 0(x0)        # Memory[0] = x1 = 5
    sw x2, 4(x0)        # Memory[4] = x2 = 12
    lw x3, 0(x0)        # x3 = Memory[0] = 5
    lw x4, 4(x0)        # x4 = Memory[4] = 12
    add x5, x3, x4      # x5 = x3 + x4 = 17

Machine Code (32-bit hex):
    0x00500093    # addi x1, x0, 5
    0x00C00113    # addi x2, x0, 12
    0x00102023    # sw x1, 0(x0)
    0x00202223    # sw x2, 4(x0)
    0x00002183    # lw x3, 0(x0)
    0x00402203    # lw x4, 4(x0)
    0x004182B3    # add x5, x3, x4

Expected Results:
    After cycle 7:
    - x1 = 0x00000005
    - x2 = 0x0000000C
    - x3 = 0x00000005 (loaded from memory)
    - x4 = 0x0000000C (loaded from memory)
    - x5 = 0x00000011 (5 + 12 = 17)
    - Memory[0] = 0x00000005
    - Memory[4] = 0x0000000C

------------------------------------------------------------
Test Program 2: Address Calculation
------------------------------------------------------------

Assembly:
    addi x1, x0, 100    # x1 = 100
    addi x2, x0, 8      # x2 = 8 (base address)
    sw x1, 4(x2)        # Memory[8+4=12] = 100
    lw x3, 4(x2)        # x3 = Memory[12] = 100

Machine Code:
    0x06400093    # addi x1, x0, 100
    0x00800113    # addi x2, x0, 8
    0x00112223    # sw x1, 4(x2)
    0x00412183    # lw x3, 4(x2)

Expected Results:
    - Memory[12] = 0x00000064 (100 in decimal)
    - x3 = 0x00000064

------------------------------------------------------------
Test Program 3: Multiple Operations
------------------------------------------------------------

Assembly:
    addi x1, x0, 10     # x1 = 10
    addi x2, x0, 20     # x2 = 20
    add x3, x1, x2      # x3 = 30
    sw x3, 0(x0)        # Memory[0] = 30
    addi x4, x0, 5      # x4 = 5
    lw x5, 0(x0)        # x5 = Memory[0] = 30
    add x6, x5, x4      # x6 = 30 + 5 = 35

Machine Code:
    0x00A00093    # addi x1, x0, 10
    0x01400113    # addi x2, x0, 20
    0x002081B3    # add x3, x1, x2
    0x00302023    # sw x3, 0(x0)
    0x00500213    # addi x4, x0, 5
    0x00002283    # lw x5, 0(x0)
    0x00428333    # add x6, x5, x4

------------------------------------------------------------
How to Use These Test Programs
------------------------------------------------------------

1. Open Instruction_Memory.vhd
2. Replace the instruction array with one of these test programs
3. Run the testbench: week6_memory_tb.vhd
4. Verify:
   - Store operations write correct values to memory
   - Load operations read correct values from memory
   - Address calculation works with base + offset
   - ResultSrc multiplexer selects correct source

------------------------------------------------------------
Verification Checklist
------------------------------------------------------------

□ MemWrite = '1' during SW instructions
□ MemWrite = '0' during LW instructions
□ ResultSrc = '1' during LW (select memory data)
□ ResultSrc = '0' during other instructions (select ALU)
□ ALU computes correct address (base + immediate)
□ Data_Memory stores values at correct addresses
□ Data_Memory reads values from correct addresses
□ Register file receives correct data for LW writeback
